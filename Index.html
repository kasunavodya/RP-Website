Introduction

With the advancement of technology, the growth of software applications has rapidly increased. Both small-scaled businesses to large-scaled corporations prefer software applications for achieving their business objectives such as marketing, automation, management, and other critical business requirements. With growing competition in software development field, the software application had to scale in a way add new features or easily respond to changing business requirements. In many aspects, scaling results in increasing the code size and complexity of the application. Automation of business process requires more effort from developers on which they need to rewrite many businesses logic across multiple individual systems. As programmers we intent to introduce a new tool named "UI BUILDER" which would facilitate developers and software organizations to automate their software development process. The tool with its ability to convert UI rough sketches to standard UI and finally providing the source code for developers on which they can build complex logic depending on their organizational needs.

LITERATURE REVIEW

Previous researchers have been conducted in recent years to develop an assistive tool for identifying dyscalculia in children. The "Dyscalculia Screener" is a program designed to evaluate the mathematical capacity of children 6- 14 years old [10],[11]. It checks the children's wicker zones by giving various questions such as arithmetic operations in mathematics and comparison. But the major limitation was it supports only screening. In another web-based solution, students had been checked in calculations, numeric concepts, and problem-solving areas. But this is not a very attractive computer-based screener for children to use [8].

"DyscalculiUm" is a web-based solution for a screening test that evaluates children with dyscalculia [12]. But it assesses students who take part in higher education only. For the screening section for this diagnose, it was used six key factors to identify. Test items were made to prove that. Refer to [13], they have developed five different cognitive tasks to screen dyscalculia patterns associated with two systems, and screening test is done by using a tablet to mobilize the tool to enable the data collection. The “Dynamo Maths” is computer software that can be used for intervention and providing a remedy for dyscalculic children who are in the 6 to 9 age range [14]. The three-stage program includes lesson plans on multi-sensory resources, interactive online modules, and worksheets for practice. The research, which was done in Thailand, the main purpose was to develop the assistive technology tool called “Calculating Aid Tools: KidKanit” to help dyscalculia students in mathematical areas [15].

The study [17], proposed a web-based learning tool as a design to improve the learning environment of different technologies of Dyscalculia students. It was only provided simple and very attractive game-based activities for the preschool students. But there was no dyscalculia identification process. Refer to [16], “Dyscalc” is a free online screening tool for students over the age of 14. Furthermore, it is also a web-based application. But nowadays the most effective way of learning things using mobile [19]. A quick (2 minute) paper-and-pencil tool was developed to evaluate the ability of children to compare symbolic and non-symbolic numerical magnitudes to resolve these outstanding problems and evaluated the degree to which individual differences in achievement are explained by success on this test [13]. A study was done for the diagnosis of dyscalculia using three classifiers rule-PART, J48, and SVM to predict the different classes of Dyscalculia. The result was got based on 8 features. Three models were created using collected data and founded SVM had better resulted in the classification of various subclasses with a higher accuracy value is 94% compared to the other two classifiers [20]. “Calculic Kids” is a mobile application-based solution to learn math concepts efficiently which is conducted using four subsets of games. But the application does not contain a proper way for progress tracking and remedy activities [21].

Research work on developing an intelligent system to diagnose and suggest remedial measures for learning disorders in children is based on the data input of child’s behaviour provided by the parents, system diagnoses the disorders and suggest the remedial measure. According to [22], The main aspect of this system is, it collects child behaviour through a questionary by their parents to diagnose disorders and provide remedies. The role of the mobile application developed in research [23] is to improve the hard life of persons with learning disabilities. The application supports individuals with learning disabilities to practice arithmetic and language disabilities to improve their brain efficiency. The contents of the computer-aided application designed consist of counting skills, place value concepts, and additional subjects which are related to mathematics lesson’s learning outcomes of primary school children as mentioned in [24].

In [25], [26], researches were conducted on identifying Dysgraphia situation and provide practice writing tasks. In [25] Time Warping algorithm and the expert system [26] have been implemented using Forward Chaining Method (FCM). Identified defects can be considered as achieved less accuracy, lack of attractive features, and providing only screening part. AR-based Dysgraphia Assistance Writing Environment (AR-DAWE) modal was developed according to [27], which addressed spelling mistake issues of Dysgraphia students. Researches which are on identifying handwriting issues of the Dysgraphia students on [28] and [29], practical questionnaire and standardized Handwriting Proficiency Screening Questionnaire (HPSQ) are used for the screening process, respectively. These researches help only for spelling issues.

According to [30], a game that is based on the clientserver architecture in which student can collect fruits by drawing different shapes circles, line. The key design principles which mainly focused were improved security for the user, interactive and informative guidance, high availability. An innovative approach system is proposed in which user can view the performance of the individual student or overall view of the class of the students which are allocated to them. The performance status of the student is evaluated through the initial conducted activities and depending on the condition of the student, the teacher may choose the most appropriate tool model for the student [31].

The research [32], system contains 3 main components like knowledge base, interface engine, user interface. In this system identifying the Dysgraphia condition is done through the decision tree where the input is analyzed by the rules which reside inside the knowledge acquisition or knowledge base of the system. To overcome these limitations and produce more accurate and reliable results, ‘Nana Shilpa’ delivers a unique mobile-based solution for screening and intervention for these two learning disability conditions.

RESEARCH PROBLEM

In under developing countries like Sri Lanka learning disability condition in primary school students are not identified or treated properly on a great no of occasions due to the lack of awareness among the teachers and parents. In the literature survey we had conducted, it has been observed out that there were not many applications that had been implemented to identify the risk of Dyscalculia and Dysgraphia Learning Disabilities in Primary School Students using the novel machine learning and deep learning techniques. Also, none of them had addressed the process of providing the intervention for the students through the application.
  • Medical examination sessions for learning disability conditions are expensive and time-consuming.

    • Normal medical examination session with the child physiatrist who is specialized in mental disability conditions can cost more than 6000 Sri Lankan rupees. For the majority of Sri Lankan low-income families, this much expense can't bear due to their day to day living expenses.

  • Absence of better and interactive user-friendly environment in the application.

    • Since the target age group is 6 to 8, it is very important to ensure that child is interested, and the child is taking the screening test without feeling awkward. For that, the application must provide an interactive and multisensory environment. But the existing applications had failed to produce that kind of environment in their applications.

  • Deficiency of novel technology concepts in applications.

    • The majority of the existing applications are not practiced and implemented using novel and featured technologies like machine learning and deep learning in order to generate more accurate and reliable results.

  • Not supported local language.

    • The significant issue of the existing applications is none of them has supported the native Sri Lankan Sinhala langue in their applications. Since the Sinhala language is the primary educational language in Sri Lankan educational system, it is vital to support the screening process, interventions, and inbuilt process navigations in Sinhala.

After the consideration of the above-mentioned complications, the main identified research problems which are required to address through this research project are how to provide a mobile application-based solution to screen and predict the risk of Dyscalculia and Dysgraphia learning disabilities in primary school students and deliver Comprehensive activities to overcome those learning disability risks.

RESEARCH OBJECTIVES

Main objective

The main objective of this research is to provide a solution which is a screening and refinement system for primary school students aged 6 – 8. The solution is a mobile application that contains screening and intervention for Verbal Dyscalculia, Operational and Practognostic Dyscalculia, Letter level Dysgraphia and Numeric Dysgraphia. Since all these mentioned Learning Disabilities are uncurable through medicine, only active practices are needed to improve the condition. For that, identifying at the early stage is very important. Based on this concept, the solution is provided using the latest techniques such as deep learning and machine learning algorithms. The final product is provided in a user-friendly, and less expensive environment to build up the basic skills such as writing, reading, understanding, and performing skills of students.

Sub objectives

From the main objective, there are four specific objectives were derived in order to provide a completed solution at the end of this research. All the mentioned screening and intervention activities below are followed under direct guidance from medical professionals.

  1. Identify the risk for Operational and Practognostic Dyscalculia and provide activities to improve the condition.

    2. The implemented ‘Nana Shilpa’ application provided both screening and intervention options for Operational and Practognostic Dyscalculia. In order to identify the risk, the implemented application contained a mathematical problem-solving activity series based on the basic mathematical concepts including enumerating, operators and comparison. As the student faces the screening test series, the test results are shown with the Dyscalculia situation as a probability. If the student turned out to be having a Dyscalculia situation, the intervention also provided. As the intervention, a set of comprehensive activities are provided by the application using a multisensory environment.

  2. Identify the risk for Lexical and Verbal Dyscalculia and provide activities to improve the condition.

    3. For the Lexical and Verbal Dyscalculia also, the ‘Nana Shilpa’ mobile application is supported both screening and refinement activities. For the screening option of Verbal Dyscalculia, a selection activity is performed. Here, the student has to select the relevant numbers based on the prior voice cuts provided by the application. In the end, Verbal Dyscalculia prediction is done based on the correctness of done questions in the activity. To identify the Lexical Dyscalculia, a pronunciation activity series is conducted as the screening option. When the student reads the number shown in the application, it is recorded as a voice clip. So, in the end, the final prediction for Lexical Dyscalculia is shown based on considering the accuracy of the accent and the pronunciation based on the recorded voice clips of reading numbers by the student. If in both categories, the prediction is shown as there is a risk, the intervention also developed. Here, after the application shows a voice-guided number, the student should say it aloud, and then select the relevant number on a selection activity.

  3. Identify the risk for Letter level Dysgraphia and provide activities to improve the condition.

    4. Implemented ‘Nana Shilpa’ application contains the ability to screen the risk for Letter level Dysgraphia and then providing intervention also. To screen the Letter level Dysgraphia, a writing test activity including letters and words is conducted through the application. The result is predicted as a risk for diagnosing Letter level Dysgraphia based on the accuracy of written letters and words. If the student is notified that there is a risk, the intervention activity also developed. It is also a test activity for writing letters with words with prior guidance from the application. Only the student has to follow what is stated in the guidance.

  4. Identify the risk for Numeric Dysgraphia and provide activities to improve the condition.

    5. Numeric Dysgraphia is a situation where students cannot write numbers accurately. So, through the developed ‘Nana Shilpa’ application, the screening for Numeric Dysgraphia as a risk and then provide remedies were implemented. First, identification for Numeric Dysgraphia is needed. So, a number writing screening test is performed. At the end of the screening quiz, the result is shown as a risk for having Numeric Dysgraphia based on the factors such as total correctness and total erase count which was taken while doing the quiz. If the student is warned as having Numeric Dysgraphia by the application, the intervention also included. It is provided as guidance-based activity. Here, also student can practice number writing with prior guidance.

  5. Keep the track of progress.

    6. All the done screening quiz results of Operational and Practognostic Dyscalculia, Lexical and Verbal Dyscalculia, Letter level Dysgraphia and Numeric Dysgraphia are stored and shown by the implemented ‘Nana Shilpa’ application separately and clearly. So, a parent or a teacher can have an idea about the progress of a diagnosed students by viewing done quiz results.

METHODOLOGY

The main objective of this application is to provide a mobile application-based solution to screen and predict the risk of Dyscalculia and Dysgraphia learning disabilities in primary school students. The “Nana Shilpa” mobile application system conducts the screening and refinement process of risk of Dyscalculia and Dysgraphia disability condition using 4 major risk identification and intervention components which are Verbal Dyscalculia, Operational and Practognostic Dyscalculia, Letter level Dysgraphia and Numeric Dysgraphia.

  1. Identify Risk of Letter Level Dysgraphia

    2. The Letter level Dysgraphia screening process has been conducted using four letters and four words in two stages . These four words and four letters were selected on the consultation of primary school teachers and teachers guide of Sri Lanka local Sinhala syllabus. The selection of letters and words were ensured that it enfolds all the sections of the alphabet. To make the screening writing process more accurate and accomplished, students are asked to write letters and words at a time, and they are facilitated with clear the canvas and undo the movements features at the screening activity user interface. The CNN model was built using the letter and word data images which were collected from non-dysgraphic and dysgraphic children from the age range 6 to 10. The model consists of 4 conv2D layers, 2 MaxPooling2D layers, a flatten layer and 2 dense layers. The conv2D layers contain 64 filters with a kernel size of 5x5 and 3x3 strides. The maxpooling2D layer contains a pool size of 2 and with 2 strides and a dense layer with 500 units. With an additional utilization process, a trained CNN model is used for the accurate screening of the risk of letter level dysgraphia condition.

    In the screening process which involves the letter and word identification through the CNN model, initially, the image is being preprocessed by converting it to greyscale, contrast is improved by applying Histogram Equalization and undergo with the binarization process. In the segmentation process, letters and words are set apart and the loss function is being used as the Multi-class Cross-Entropy of the CNN model. To screen the risk, letter level accuracy probability of written letters and words, total correct count of the letters and words and total erase count are being fed to the SVM model and utilized output results are used to determine the risk of having letter level dysgraphia. These results which include the date which the test has been performed, risk probability of having Letter Level Dysgraphia are being stored as the report in the database for the further reference of the parents and teachers.

    Upon the result of having the risk of letter level dysgraphia, extensive intervention activities are provided to the student. The intervention activities are provided in two stages which are for intervention for letters and words. Letters and words are given to the students with the proceeding path which involves animations show from the start point to the endpoint of the path. The total process is conducted with background voice guidance and a mission-based story. The process is designed to obtain a more user-friendly and interoceptive learning process in which students can experience more positive outcomes.

  2. Identify the risk of operational & practognostic dyscalculia

    3. In Operational and Practognostic Dyscalculia screening, an interactive mathematical quiz covering various areas was carried out to identify the children who suffer from dyscalculia or non- dyscalculia. Initially, enumerating (counting) quiz were given, and in the next stages comparison of numbers and objects quiz as well as the mathematical operation-based quiz covering the addition and subtraction carried respectively refer to Fig. 3.b. In training the model, 225 quiz results were gathered from both dyscalculic and non-dyscalculic school children for each stage of the screening test, within the age group 6 to 8. The trained model was created using the scikit-learn machine learning library in python. A screening test for dyscalculia was developed which uses a question bank to carry out the test. In each stage of the screening test, students get various questions that are stored in the SQLite database on a random basis.

    Here, performs classification by finding the hyper-plane that differentiates the two classes by using a SVM supervised learning algorithm. SVM predicts whether the students or children are having dyscalculia or not by using six (a) Enumerating quiz (b) Operation: addition parameters. Along with the SVM Radial Basis Function (RBF) kernel was used to train the most optimal model to get a more accurate result since the data set is non-linear. To screening the risk of having dyscalculia, the score of the mathematical operation-based quiz covering the addition and subtraction and average time to complete the mathematical operation-based quiz, the score of the enumerating (counting) quiz and an average time to answer the enumerating quiz, and finally sore of the comparison of numbers and objects quiz and an average time to complete the comparison of numbers and objects quiz will be taken as input to the model. These six features fed to the trained SVM model. The SVM model will then identify the child as regular or dyscalculia affected child. Further, screening results can be seen by selecting an attempt of the screening report of the student.

    If the student is at risk of dyscalculia set of comprehensive activities with a multisensory learning environment will be given. It was further divided into four categories to practice mathematical addition operation, mathematical subtraction operation, enumerating, and comparison of numbers and objects. In mathematical addition operation there are four stages and eventually in each stage students will get the different concept of addition. In the first stage, students will be given a simple exercise to add two numbers and choose the corresponding answer represented in the blue Graphical card as shown in Fig. 4.b. After finishing the practice quiz students can review the quizzes that student has done. Likewise, all the categories have questions to improve the student’s skills. After consultation with medical professionals, the remedy was planned to enhance the observation and skills of Operational and Practognostic Dyscalculia children.

  3. Identify the risk of numeric dysgraphia

    4. Implemented ‘Nana Shilpa’ application provides both screening and intervention processes including more other features. The drawable canvas is provided by the application for the screening process. The application requires to write digits from 0 to 9 each twice to reach for more accuracy level. While writing digits, the correctness, erase count, time taken to complete the task as well as boundary touch count is taken per question to the Number Dysgraphia prediction. The result is provided as a probability of having Number Dysgraphia.

    A CNN model is trained to check the accuracy of the written digit. Using the Modified National Institute of Standards and Technology (MNIST) number dataset imported from Keras, the model is trained. 19 layers and 20 epochs were used to achieve high accuracy from the CNN model. After trained the CNN model, it is downloaded as a TensorFlow lite file which is more convenient to use in the android environment. After writing a digit, a written digit image is converted to a Bitmap file and go through the added TensorFlow lite file. It returns the identified digit from the provided digit. If it is identified as correct, that quiz is correct. There are all 20 questions including from 0 to 9 each twice. After completion of the screening quiz, the results are shown which are total correctness, total erase count, total time is taken and total boundary touch count. Here, total correctness is based on how many questions are correct from 20 questions. A ML model is trained to predict the result using the results provided by the screening task. Based on the trained data in the ML model, it returns the result as a probability of whether a student has a risk for Numeric Dysgraphia or not. To catch the progress of a student, a parent can view the report which includes done quiz results.

    If the implemented application predicts that there is a probability of having Numeric Dysgraphia, the system will redirect to the intervention interface. The intervention interface is provided in a gaming environment where the student can write digits from 0 to 9 with guidance. For each number, it provides graphical images which represents the written number, after done the writing. The process of intervention is implemented to obtain improved motor skills and observation in children who are undergoing the dysgraphic condition with the help of educational and medical specialists.

  4. Identify the risk of verbal and Lexical dyscalculia

    5. In the Lexical Dyscalculia screening test, the application will provide background voice guidance and display a random number from a predefined number set of 12 which were chosen from 0 to 1000, considering 3 categories with the ones, tens, hundreds as Fig. 6.a. User has to press the microphone button and pronounce the displayed number. The user needs to perform this test five times and at the end, the application will show the risk percentage of Lexical Dyscalculia. The fact consider here is whether the user identifies the displayed number and pronounces it correctly.

    A CNN used with five layers to identify Lexical Dyscalculia risk. It consists of three convolutional layers with batch normalizer, Maxpool2D layers, and “ReLu” activation function in each. The output flattens into 1D using a dense layer that consists of 64 neurons and a dropout layer and it feeds into another dense layer with 12 neurons and a softmax classifier. The final output goes through “Adam optimizer” and sparse categorical cross-entropy is used as the loss function for better results. CNN model trained using pronunciations of 12 chosen numbers with 3 parts as train, validation, and test. 0.1 of the data set (10% of the whole) taken as test data, 0.1 from remaining data (9% of the whole) as validation. The rest has taken as the train split. Before feeding into the CNN model, a set of preprocessing steps followed. MFCCs of the audio file extracted as the feature for audio classification which is the best and most commonly used. Take snapshots at different segments of audio and used 13 MFCCs using the Librosa library.

    In the Verbal Dyscalculia identifying test, with background voice guidance and recorded audio of the pronunciation of the number is played and user needs to select the correct answer played in the audio. The user is required to perform the activity five times and the risk of Verbal Dyscalculia percentage will be calculated using the data of the activity against the voice record played in the activity. The screening process is conducted to identify whether the user identifies the correct number according to voice pronunciation. The data related to each activity will be added to the database after performing and displaying the identifying test result. Remedy practices will provide an example activity of how to pronounce & select the correct number. Users can choose from three examples which are given from three categories with the ones, tens, hundreds each. The application will train the user on how to pronounce the number and give time to pronounce the number and also select the pronounced number from different answers.
